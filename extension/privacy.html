VibePrompt Privacy Policy

Last updated: October 8, 2026

VibePrompt is a Chrome extension that helps adapt prompts you type into supported GenAI chat sites. This policy describes what data is handled and how.

Data we process

  • Prompt text and chat context — When you click Adapt now, the extension reads text from the chat composer and a short recent conversation snippet from the page, then sends them to the Backend URL you configure so the adaptation API can run.
  • Groq API key (optional) — If you paste a key in Settings, it is stored in Chrome local storage on your device and sent only to your configured backend (via request headers/body) so that backend can call Groq. The extension does not send the key to any other third party.
  • Personal vocabulary — Optional typo/abbreviation preferences learned locally are stored in Chrome local storage and may be included in adapt requests to your backend.
  • Settings — Backend URL is stored in Chrome sync storage; API key stays in local storage.

What we do not do

  • We do not sell personal data.
  • We do not use your prompts for advertising.
  • We do not collect analytics, accounts, or browsing history beyond the supported chat pages where the content script runs.
  • By default, Adapt requests go to the production API at https://vibeprompt.onrender.com. You can change Backend URL to another host you control.

Third parties

Adaptation uses the backend you configure. That backend typically calls Groq (or another LLM provider you wire in). Your prompts and any API key you supply are subject to that backend operator’s and the LLM provider’s policies. If you self-host the included FastAPI backend, data stays on the machine/service you run.

Permissions

  • storage — Save settings and local vocabulary.
  • Optional host access — Requested only for the Backend URL origin you save, so the extension can call your API.
  • Content scripts — Injected only on listed GenAI chat sites to read the composer, show the panel, and insert adapted text when you choose.

Data retention & deletion

Settings and vocabulary remain in your browser until you clear them (Settings → Clear API key, or Chrome’s extension/site storage controls) or uninstall the extension. Prompt data retention on your backend is controlled by how you operate that backend.

Children

VibePrompt is not directed at children under 13.

Contact

For privacy questions about this extension, open an issue on the project repository that distributes VibePrompt, or contact the publisher listed on the Chrome Web Store listing.
