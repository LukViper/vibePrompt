# Glossary

**Alternative Approaches** — Prompt pattern that lists best alternate ways to accomplish a task within scope X, optionally with pros/cons and a choice prompt (Ch 5).

**Cognitive Verifier** — Prompt pattern that subdivides a question into additional questions, then combines answers into the overall response (Ch 5).

**Context Control** — Pattern category for managing what the LLM considers or ignores in conversation (Ch 7).

**Context Manager** — Prompt pattern to consider Y, ignore Z, and optionally start over within scope X (Ch 7).

**Error Identification** — Pattern category for surfacing facts/assumptions and rationales so users can verify outputs (Ch 4).

**Fact Check List** — Prompt pattern that appends (or inserts) fundamental facts the answer depends on for user verification (Ch 4).

**Flipped Interaction** — Prompt pattern where the LLM asks questions to achieve goal X until a termination condition (Ch 6).

**Fundamental contextual statements** — Core ideas a prompt pattern must communicate; wording may vary, statements should not (Ch 1).

**Game Play** — Prompt pattern that creates a rules-constrained game around topic X with model-generated content (Ch 6).

**Infinite Generation** — Prompt pattern that repeatedly generates outputs without re-entering the generator prompt (Ch 6).

**Input Semantics** — Pattern category for how the LLM interprets input languages/notations (Ch 2).

**Interaction** — Pattern category for turn-taking, games, and repetitive generation (Ch 6).

**Meta Language Creation** — Prompt pattern: when I say X, I mean Y (or do Y); teaches an alternate language for the session (Ch 2).

**Output Automater** — Prompt pattern that emits a concrete executable artifact to perform recommended steps (Ch 3).

**Output Customization** — Pattern category for constraining type, format, role, structure, or packaging of outputs (Ch 3).

**Persona** — Prompt pattern: act as persona X and provide outputs that persona X would create (Ch 3).

**Prompt** — Instructions that program an LLM by customizing/enhancing/refining capabilities and interaction (Ch 1).

**Prompt engineering** — Programming LLMs via prompts (Ch 1).

**Prompt Improvement** — Pattern category for refining questions, alternatives, subdivision, and refusal handling (Ch 5).

**Prompt pattern** — Reusable documented solution for LLM output/interaction problems, analogous to software patterns (Ch 1).

**Question Refinement** — Prompt pattern that suggests a better version of the user’s question within scope X (Ch 5).

**Recipe** — Prompt pattern that completes a step sequence from partial ingredients toward goal X, flagging missing/unnecessary steps (Ch 3).

**Reflection** — Prompt pattern that explains reasoning and assumptions behind answers (Ch 4).

**Refusal Breaker** — Prompt pattern that, on can’t-answer, explains why and offers alternate wordings (ethical use only) (Ch 5).

**Software pattern** — Reusable solution to a recurring problem in a context; structural ancestor of prompt patterns (Ch 1).

**Template** — Prompt pattern that forces output into a provided skeleton with placeholders (Ch 3).

**Visualization Generator** — Prompt pattern that emits text for an external visualization tool rather than images directly (Ch 3).
