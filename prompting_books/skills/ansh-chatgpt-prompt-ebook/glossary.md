# Glossary — Ansh Mehra ChatGPT eBook (Think School)

**AIDA** — Persuasion structure: Attention, Interest, Desire, Action; used to constrain cold-email prompts (Ch 5).

**Actionable step (closing)** — Required one next action at the end of personality-mentorship answers (Ch 3, Ch 6).

**Active practice loop** — Document learnings, type prompts yourself, build on AI output; don’t paste blindly (Ch 1).

**Assign a Role** — First Prompt Anatomy slot: cast the model as mentor, coach, specialist, game, or interviewer (Ch 3–7).

**Becoming friends with GPT** — Learn how the model behaves so collaboration feels natural; it won’t volunteer help (Ch 4).

**Cold email specialist prompt** — Role + named recipient + product features + personal benefits + AIDA + reply-seeking tone (Ch 5).

**Component state checklist** — Table of interactive states and edge cases for UI components in a design system (Ch 7).

**Constraint / Give constraints** — Limits and sequencing that prevent one-shot megalith asks (Ch 4).

**Content calendar** — Planned mix of posts (often curated + original) aimed at engagement/followers (Ch 5, Ch 6).

**Context dump** — Rich personal/situational detail so plans fit the asker (Ch 4).

**Curated vs original content** — Calendar mix balancing shared posts and creator-made posts (Ch 6).

**Define the Goal** — Anatomy slot stating the outcome metric or success condition (Ch 3, Ch 5–7).

**Define the Task** — Anatomy slot stating the concrete deliverable (Ch 3–7).

**Durable skills vs perishable tips** — Prompt/constraint craft lasts; UI-specific tips age out (Ch 10).

**Edge cases (UI)** — Non-happy-path states a design system must specify (Ch 7).

**Framing** — Switching GPT into a persona/perspective before stating the need (Ch 4).

**Free vs paid ChatGPT tier** — Book snapshot: practice on free access before upgrading models (Ch 2).

**Interactive states** — UI control states such as default, pressed, disabled, loading, focus (Ch 7).

**Legendary personality mentorship** — Answer as a named person using their mental models, process, and tone (Ch 3, Ch 6).

**Method–question fit** — Choosing user-research methods from the research question (Ch 7).

**Midjourney** — Image-generation tool cited for ongoing multimodal practice alongside ChatGPT (Ch 8, Ch 10).

**Prompt** — Any message typed into an AI tool (Ch 1).

**Prompt Anatomy** — Role → Task → Goal → Constraints/Expectations blueprint used throughout the ebook (Ch 3–7).

**Prompt Engineering** — Skill of writing prompts that produce strong results (Ch 1, Ch 8).

**PromptBase** — Marketplace to buy/sell prompts for ChatGPT, DALL·E, Midjourney (Ch 8).

**Set Expectations** — Explicit output shape (calendar, table, feedback after interview) (Ch 5, Ch 7).

**Shy class-topper metaphor** — GPT is highly capable but quiet until asked explicitly (Ch 4).

**Social media coach prompt** — Niche coach + follower baseline/target + audience + topics + strategy + calendar (Ch 5).

**Sponsor demonstration criteria** — Show how a product simplifies, saves time, or elevates results inside content (Ch 6).

**Task decomposition** — Splitting book-scale work into ordered prompts that feed each other (Ch 4).

**Trivia game prompt** — Rule-explicit interactive quiz with scoring, win/lose, wait-for-answer, stop/reset (Ch 3).

**Turn-based mock interview** — Interviewer persona asks one question at a time and waits (Ch 7).

**Uncommon + underrated resources** — Constraint that pushes past generic resource lists (Ch 3).

**Weekly skill-routine prompt** — Senior subject mentor builds a weekly practice plan for a focus topic (Ch 3).

**Wellbeing triad** — Exercise, nutrition, sleep as equal priorities beside AI skill (Ch 10).
