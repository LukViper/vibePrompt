# Cheatsheet — Ansh Mehra ChatGPT eBook (Think School)

## Decide the prompt pattern

| If you need… | Do this | Because |
|---|---|---|
| Better answers generally | Run **Prompt Anatomy**: Role → Task → Goal → Constraints/Expectations | Underspecified chat is the default failure |
| Domain judgment | **Frame** a narrow specialist persona first | Perspective beats generic helpfulness |
| A plan that fits *you* | **Context dump** background, timeline, geo, skill level | One-liners get one-line plans |
| A book/course/system | **Decompose** into sequenced prompts; feed outputs forward | One-shot megaliths collapse quality |
| A practice schedule | **Weekly mentor routine** + uncommon/underrated resources | Cadence + non-generic inputs |
| A thinker’s lens | **Personality mentorship** + one actionable closer | Voice without action is entertainment |
| Theory drill | **Trivia game** with score, wait, stop/reset rules | Games without rules break turn-taking |
| Social growth plan | Coach + realistic metrics + **calendar** | Ideas ≠ operating system |
| Ad that converts | Specialist copywriter + audience + channel + **features→benefits** | Pretty copy without conversion logic fails |
| Cold outreach | **AIDA** + named person + personal benefits | Structure + personalization raise replies |
| Sponsored content | Dual format + **demo criteria** (simplify/save/elevate) | Name-drops feel like ads |
| UX research literacy | Mentor brief: steps + examples + method fit + tools | Process > slogans |
| Design-system completeness | **State table** including edge cases | Happy path only ships bugs |
| Interview prep | **Turn-based** interviewer; wait for answers | Script dumps aren’t practice |
| Learning from templates | Type/adapt; don’t blind-paste | Comprehension is the skill |

## Prompt Anatomy checklist (use every time)
1. **Role** — senior + specialty + niche?
2. **Task** — concrete artifact named?
3. **Goal** — success metric or purpose clear?
4. **Constraints** — quality bars, formats, rules, what *not* to do?
5. **Expectations** — calendar/table/feedback/wait behavior stated?
6. **Human layer** — will you edit/build on the output?

## Framing sharpness

| Weak frame | Stronger frame |
|---|---|
| Act as a nutritionist | Act as a professional nutritionist specializing in muscle building for young males |
| Act as a marketer | Act as a social media coach specializing in Technology and Design content |
| Help my career | Act as… + year/degree/target job/geo/current skills/12-month free-resource plan |

## Decomposition default (large creative work)
1. Topic list for a persona → 2. Index + catchy titles → 3. Subheads per chapter → 4. Expand → 5. Re-ingest (“explain like I’m 10”) → 6. **You** rewrite.

## Interactive prompt tells
- **Smell: model dumps everything** → missing “wait for my response / one at a time.”
- **Smell: quiz invents scoring** → declare points, win/lose, stop/reset phrases.
- **Smell: interviewer breaks character** → “only reply as the interviewer; no explanations.”

## Goal realism (marketing)
- Prefer **sustainable strategy** language when targets are aggressive.
- If organic growth goals look impossible, keep the calendar/audience work; drop unethical acceleration.

## Resource & tool maintenance
| Cadence | Do |
|---|---|
| Weekly | Rewrite 2–3 library prompts in your domain (Ch 8) |
| Weekly | Scan one AI directory + one news item (Ch 9) |
| Ongoing | Practice constraints; treat UI tips as disposable (Ch 10) |
| Daily/weekly | Protect exercise, nutrition, sleep—non-optional |

## Defaults worth memorizing
- **Clarify purpose** of the prompt explicitly.
- Ask for **uncommon + underrated** when researching resources.
- End mentorship answers with **one actionable step**.
- Prefer **table format** for checklists/states.
- **Build on** completions; don’t ship raw paste.
