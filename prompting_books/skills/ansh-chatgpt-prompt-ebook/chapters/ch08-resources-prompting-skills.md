# Chapter 8: Best Resources to Improve Prompting Skills

## Core Idea
ChatGPT’s power unlocks through better prompt engineering—practice regularly via curated prompt libraries, beginner curricula, verb/tone tables, communities, and marketplaces (including selling prompts).

## Frameworks Introduced
- **Resource Portfolio for Prompt Skill**: Mix directories, courses, example banks, communities, and marketplaces.
  - When to use: After learning core anatomy (Ch 3–4) and needing deliberate practice volume.
  - How: Rotate study (structured lessons) + imitation (example prompts) + creation (write/sell your own).
- **Marketplace-as-feedback loop**: Studying what others buy/sell reveals in-demand prompt patterns.
  - When to use: Career interest in prompt engineering as a skill companies will hire for.
  - How: Browse PromptBase-like markets for ChatGPT/DALL·E/Midjourney prompts; note structure and niches; optionally sell strong originals.
- **Regular practice cadence**: Skill compounds from repeated use of libraries, not one read of an ebook.
  - When to use: Anytime results plateau.
  - How: Schedule weekly sessions on PromptVine / LearnPrompt-style sites; rewrite prompts in your voice (Ch 1 rule).

## Key Concepts
- **PromptVine (promptvine.com)**: Broad, easy prompt collections across conversation and professions.
- **SaaS Prompts (saasprompts.com)**: Startup/SaaS-oriented prompt help for building better platforms.
- **Learn Prompting (learnprompting.org)**: Free open-source beginner→advanced prompt engineering curriculum.
- **LearnPrompt.org**: 1500+ prompts plus verbs/tones tables for more accurate answers.
- **Datafit (datafit.ai)**: Community of prompt writers; topical banks (marketing, coding, finance, writing, gaming, art).
- **PromptBase (promptbase.com)**: Buy/sell marketplace for ChatGPT, DALL·E, Midjourney prompts.
- **Prompt engineering as career skill**: Rising demand as companies lean on AI models.

## Mental Models
- Use **learnprompting.org** when you need systematic theory, not just templates.
- Use **example banks** when you need pattern recognition across domains.
- Use **verb/tone tables** when answers are accurate but wrong in voice or actionability.
- Use **marketplaces** when you want signal on which prompts people value enough to pay for.
- Prefer **practice over bookmarking**—saved links ≠ skill.

## Anti-patterns
- **Collecting resources without rewriting prompts**: Hoarding replaces learning.
- **Copy-paste marketplace prompts into production unchanged**: Misses Ch 1 comprehension rule.
- **Ignoring beginner curricula because you “already chat daily”**: Casual chat ≠ engineered prompts.
- **Treating site lists as permanent**: URLs and catalogs change; the portfolio *types* endure.

## Worked Example
**Weekly practice plan using the chapter’s resource types**:
1. **Mon (theory)**: One Learn Prompting chapter; note one technique in Notion.
2. **Wed (imitation)**: Pick 3 PromptVine or Datafit prompts in your job domain; type rewritten versions with your role/task/constraints.
3. **Fri (tone drill)**: From LearnPrompt-style verb/tone tables, regenerate yesterday’s prompt in two tones; compare usefulness.
4. **Monthly (market scan)**: Skim PromptBase top prompts in your niche; extract anatomy, don’t paste wholesale.
5. **Optional income loop**: Package a proven personal prompt with clear inputs/outputs and list it.

**Key takeaway alignment**: Practice regularly; PromptBase uniquely enables selling skills.

## Key Takeaways
1. Better prompts unlock ChatGPT—resources exist to accelerate that skill.
2. Combine curricula, libraries, communities, and marketplaces.
3. Verb/tone tooling refines voice beyond content accuracy.
4. Prompt engineering is becoming economically valuable; study what sells.
5. Regular practice beats a one-time ebook finish.
