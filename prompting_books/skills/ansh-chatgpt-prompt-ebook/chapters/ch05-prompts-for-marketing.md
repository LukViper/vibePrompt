# Chapter 5: Prompts for Marketing

## Core Idea
Marketing prompts succeed when a specialist role meets measurable goals, audience truth, product features, and format constraints—illustrated with social calendars, Instagram ad copy, and **AIDA**-structured cold emails.

## Frameworks Introduced
- **Prompt Anatomy (marketing variant)**: ASSIGN A ROLE → DEFINE THE TASK → DEFINE THE GOAL → SET EXPECTATIONS / CONSTRAINTS.
  - When to use: Any growth, copy, or outreach prompt.
  - How: Coach/copywriter/email specialist + concrete deliverable + numeric or conversion goal + output shape (plan, calendar, ad, email).
- **Social Media Coach + 30-Day Calendar**: Mentor an Instagram profile with baseline followers, stretch goal, niche, audience, topics, strategy, and upload calendar.
  - When to use: Need a content/growth plan, not isolated post ideas.
  - How: Act as social media coach in a niche; state current followers + target + timeline; require audience, topics, strategy, and day-by-day calendar. Keep goals realistic.
- **Sr. Copywriter Ad-Copy Prompt**: Role + brand/product + channel + audience + conversion objective + feature list.
  - When to use: Paid or organic ads that must convert a defined segment.
  - How: Specialize the copywriter (e.g. handbags); name brand; channel (Instagram); audience budget/style; list features that map to benefits.
- **AIDA Cold Email Prompt**: Cold-email specialist + named recipient/context + product features + personal benefits + **AIDA** structure + personalized, short, response-seeking tone.
  - When to use: Influencer or prospect outreach introducing a product.
  - How: Attention → Interest → Desire → Action baked into instructions; include features and personal-life benefits; name the person and their role.

## Key Concepts
- **AIDA**: Attention, Interest, Desire, Action—classic persuasion scaffold for cold email.
- **Set Expectations**: Explicit deliverables (e.g. 30-day calendar) beyond the core ask.
- **Feature → benefit translation**: Copy and email must show why features matter to the reader.
- **Realistic goal setting**: Stretch targets (e.g. 2.5k → 100k in 30 days) need honesty about organic limits.
- **Personalization**: Named recipient and context raise reply odds.

## Mental Models
- Use a **social coach + calendar** when consistency is the growth bottleneck.
- Use **specialist ad copy roles** when generic “write an ad” yields bland claims.
- Use **AIDA** when cold email rambles without a persuasion path.
- Prefer **features listed in the prompt** when you need benefit-led copy.
- Keep niche and follower goals **specific and believable** so plans stay actionable.

## Anti-patterns
- **Impossible growth targets without strategy caveats**: Model may invent unethical shortcuts; demand sustainable tactics.
- **Ad copy without audience or features**: Pretty words, no conversion logic.
- **Cold email without AIDA or personalization**: Looks like a blast template.
- **Omitting channel**: Instagram vs email vs search need different voice and length.

## Worked Example
**Ad copy anatomy (Alex Jetbags / Jetblack Handbags)** — reconstructed:

| Slot | Fill |
|------|------|
| Role | Sr. Copywriter specializing in handbag ads |
| Task | Instagram ad for Alex Jetbags / Jetblack Handbags |
| Audience | College students, average budget, stylish + durable |
| Objective | Communicate features/benefits → drive conversions |
| Features | Waterproof, durable, clean/minimal, 3 pockets, USB charge slot, laptop storage |

**Cold email AIDA ask (FitPulse)**: Role = cold email specialist; Recipient = fitness influencer; Product features listed; Constraint = personal benefits + AIDA; Expectation = personalized, engaging, to-the-point for replies.

**Good completion shape**: Subject that hooks → personal nod → feature/benefit stack → clear CTA—not a feature dump with no desire/action.

## Key Takeaways
1. Marketing prompts need role, goal, audience, and output expectations.
2. Calendars beat one-off ideas for social growth discipline.
3. Ad prompts must encode channel, persona budget, and feature list.
4. Structure cold email with **AIDA** plus personalization.
5. Realistic goals produce usable strategies; fantasy targets produce noise.
