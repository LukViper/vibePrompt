## Core Frameworks & Mental Models

### Prompt Engineering
Use **Prompt Engineering** when weak chats produce weak results—every message is a **Prompt**; design it. Prefer principles over perishable UI tips as tools change (Ch 1, Ch 10).

### Active study loop (author method)
Use **document → type yourself → build on output** when learning any template library. Don’t copy-paste blindly; don’t treat AI output as finished work (Ch 1).

### Prompt Anatomy
Use this blueprint for nearly every serious ask (Ch 3–7):
1. **ASSIGN A ROLE** — senior + specialty + niche
2. **DEFINE THE TASK** — concrete deliverable
3. **DEFINE THE GOAL** — purpose or metric
4. **SET CONSTRAINTS / EXPECTATIONS** — quality bars, formats, wait rules, calendars, tables

Clarify the **purpose** of the prompt explicitly.

### Framing
Use **Framing** when domain perspective matters: switch GPT into a relevant professional *before* the ask. Prefer narrow specialty (`nutritionist who specialises in muscle building for young males`) over bare titles (Ch 4).

### Best-friend context dump
Use rich context (timeline, background, location, starting skill, free-resource needs) when one-line career/learning asks fail. Talk as if to a best friend with unlimited listening capacity (Ch 4).

### Constraints & decomposition
Prefer **sequenced constrained prompts** over one megalith when building books/systems: topics → index/titles → subheads → expand → simplify (“like I’m 10”) → **you** rewrite (Ch 4).

### Becoming friends with GPT
Think of GPT as a **shy class topper**: highly capable, low initiative—ask explicitly; learn how it reads/thinks so collaboration improves (Ch 4).

### Weekly skill-routine prompt
Use when you need practice cadence: senior `[subject]` mentor + focus topic + **uncommon advice** + **underrated resources** (Ch 3).

### Legendary personality mentorship
Use when you want a named thinker’s mental models and tone; **end every answer with one actionable step**. Works for career doubts and content-engagement strategy; can request multiple personalities (Ch 3, Ch 6).

### Rule-explicit trivia game
Use for theory drills: MCQs, points, win/lose thresholds, wait-for-answer, stop/reset phrases—never rely on assumed game rules (Ch 3).

### Social coach + calendar
Use for Instagram/growth planning: niche coach + current followers + target/timeline + audience + topics + strategy + upload calendar. Keep goals **realistic** (Ch 5, Ch 6).

### Feature-led ad copy
Use specialist copywriter + brand + channel + audience + conversion objective + feature list → benefits (Ch 5).

### AIDA cold email
Use **AIDA** (Attention → Interest → Desire → Action) with named recipient, product features, personal benefits, and concise personalized tone to raise reply odds (Ch 5).

### Sponsored dual-format content
Use niche creator + educational video/tutorial + companion blog + sponsor **demo criteria** (simplify, save time, elevate result) + audience (Ch 6).

### UX mentor / design-system table / mock interview
- Research: senior UX mentor → steps + examples + method-by-question + low-cost tools (Ch 7)
- Components: design-system manager → **table** of interactive states + edge cases (Ch 7)
- Interviews: recruiter persona → one question at a time → wait → later feedback/resources (Ch 7)

### Ongoing practice system
Combine prompt libraries (PromptVine, Learn Prompting, LearnPrompt, Datafit, SaaS Prompts, PromptBase) with AI tool directories/news (Futurepedia, Eluna, AI News, There’s An AI For That). Practice ChatGPT + image tools; protect exercise, nutrition, sleep. **AI won’t replace you—humans who use AI might** (Ch 8–10).
