# Chapter 9: Tutorials (Practice Drills)

## Core Idea
Six tutorials lock in the task families: attempt questions before peeking at answers; many prompts work; Creativity settings are part of the solution; data is fictional unless noted.

## Frameworks Introduced
- **Tutorial 1 – Rewriting**: Translate a famous quote; simplify Digital Government Blueprint prose for a 6-year-old (examples/analogies, no hard vocab); correct launch-copy typos and list the changes.
  - Creativity: Balanced (0.5) in sample answers.
- **Tutorial 2 – Extracting**: Names → table (Last, First, Last+First); crime report → per-person schema (Name, Age, Sex, Nationality, Crime/items); trip report → action items (even when buried mid-paragraph).
  - Creativity: Balanced (0.5).
- **Tutorial 3 – Clustering**: Mixed books/songs/animals → 3 named groups + unsure Group 4; partner call reports → Follow-up Actions vs Lower Interest, include concerns, summarize, **do not invent**.
  - Creativity: Low (0) in sample answers.
- **Tutorial 4 – Classifying**: Course feedback → Positive / Negative / Neutral by Feedback ID; estate feedback → Departments L/S/N (Littering/Smell/Noise).
  - Creativity: Low (0).
- **Tutorial 5 – Summary**: Two conflicting Digital Payment news pieces → succinct joint summary + ministry follow-up bullets; partner reports → cluster then summarize groups without new content.
  - Creativity: Balanced then Low per answer key.
- **Tutorial 6 – Generate**: Tech conference marketing — 5 taglines; keynote synopses with CTA; community email (2 paragraphs) highlighting Guest of Honour. No single right answer — judge quality yourself.
  - Creativity: High (1).

## Key Concepts
- **Attempt-first pedagogy**: Struggle before answers.
- **Creativity as part of the prompt recipe**: Documented beside each answer.
- **Schema prompts**: Field lists and group definitions in the instruction.
- **Anti-invention clause**: “Do not make up new contents” for ops summaries.
- **Leftover / neutral bins**: Group 4 unsure; Neutral for unusable feedback (“testing, testing”).
- **Buried action-item detection**: Extraction must scan whole document.

## Mental Models
- Use **Balanced** when Y = rewrite/translate/extract with some fluency.
- Use **Low** when Y = clustering, classifying, or no-invention summaries.
- Use **High** when Y = taglines, synopses, inspiring marketing copy.
- Prefer **explicit group definitions** in the prompt (animals/music/books; Dept L/S/N).
- Prefer **multi-step instructions** when Y = classify then summarize.

## Anti-patterns
- **Reading answers first**: Skips skill building.
- **Wrong creativity for the task**: High creativity on routing/classification.
- **Omitting “do not invent”** on ministry/partner digests.
- **Expecting identical model output**: Versions drift; grade structure, not string match.

## Worked Example
**Tutorial 1 Q2 pattern (reconstructed compactly)**  
Paste DGB paragraph → “Rewrite into a summary a 6-year-old can understand. Do not use difficult vocabulary. Add examples/analogies a child knows.” → Child-level Smart Nation analogies (tablet games, bike helmet safety).

**Tutorial 3 Q2 pattern**  
Paste seven partner reports → “Cluster into Group 1 follow-up actions vs Group 2 lower interest; show concerns; summarize each group; do not make up new contents.” → ABC/JKL/STU vs DEF/GHI/MNO/PQR-style buckets.

**Tutorial 6 stack**  
High creativity: brainstorm 5 taglines → generate each keynote synopsis + CTA → compose mailing-list email from venue/time/GOH + synopses + partners.

## Key Takeaways
1. Practice all six task types with real prompt shapes.
2. Match Creativity to task risk and creativity need.
3. Spell schemas, departments, and anti-invention rules.
4. Extraction should catch buried action items.
5. Generate tutorials are judged qualitatively, not by a single gold string.
