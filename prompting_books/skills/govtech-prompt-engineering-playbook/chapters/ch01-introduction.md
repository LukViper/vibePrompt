# Chapter 1: Introduction

## Core Idea
Prompt engineering is the practical skill of steering LLM-powered AI with natural-language instructions so everyday work gets done faster — the risk is being displaced by people who master AI, not by AI alone.

## Frameworks Introduced
- **Narrow AI vs. sentient AI**: Treat today’s systems as powerful task tools, not movie-style general intelligence.
  - When to use: Setting expectations with stakeholders who over- or under-estimate ChatGPT-class tools.
  - How: Separate “does this task well” from “understands like a human.”
- **Plain-language interface**: Prefer English (or natural language) instructions over code for many knowledge tasks.
  - When to use: Non-developers adopting LLM chat apps.
  - How: State intent clearly; iterate; verify outputs.

## Key Concepts
- **Prompt engineering**: Crafting inputs so responses are more accurate, relevant, and useful.
- **LLM-powered AI**: Chat systems driven by large language models (e.g. ChatGPT-class tools).
- **Turing Test (context)**: Historical benchmark for human-indistinguishable machine behaviour — still not the right success metric for work tools.
- **Narrow AI**: Systems strong at specific trained tasks (chess, Go, vision) rather than open-ended agency.
- **Displacement framing**: Worry less about AI replacing you; more about peers who use AI better.

## Mental Models
- Use **autocomplete-with-authority** when judging LLM replies: fluent ≠ knowledgeable.
- Think of the playbook as a **work amplifier**, not a path to sentient AI.
- Prefer **safe harnessing now** over waiting for theoretical AGI debates.

## Anti-patterns
- **Treating chatbots as human replacements**: Brittle when instructions vary slightly.
- **Ignoring the skills race**: Focusing only on “will AI take jobs” instead of upskilling in prompts.
- **Confusing fiction with capability**: Jarvis/Skynet narratives skew expectations.

## Worked Example
**Situation**: A colleague says “ChatGPT means we finally have Iron Man’s Jarvis.”
**Playbook stance**: Acknowledge the leap in natural-language interaction and useful replies, then reframe: underlying tech is still far from human cognition; the actionable question is how to use it safely for today’s tasks via better prompts.

## Key Takeaways
1. LLM chat changed access: type intent in plain language, get surprisingly useful replies.
2. Capability ≠ sentience; treat outputs as drafts needing judgment.
3. Prompt engineering is the lever for non-specialists to benefit.
4. Competitive risk: humans who master AI outperform those who don’t.
5. This playbook moves from basics → CO-STAR → task prompts → advanced tips → tutorials.
