# Glossary

**Audience (CO-STAR A)** — Who the output is for; drives vocabulary and examples (Ch 4)

**Balanced (Creativity)** — LaunchPad Creativity preset mapped to Temperature 0.5 (Ch 3, Ch 9)

**Chain Of Thought / Step by Step** — Prompting the model to show workings; may improve answers (Ch 8)

**Classifying (Task – Classifying)** — Assign text to predefined labels/categories (Ch 6, Ch 9)

**Clustering (Task – Clustering)** — Group items by similarity or a stated criterion (Ch 6, Ch 9)

**CO-STAR** — Context, Objective, Style, Tone, Audience, Response — primary prompt checklist (Ch 4)

**Context (CO-STAR C)** — Background that scopes the topic; often placed above Objective (Ch 4)

**Correction** — Rewriting subtype for grammar/spelling and sentence improvement (Ch 5, Ch 9)

**Creativity** — LaunchPad synonym for temperature (Low/Balanced/High ↔ 0 / 0.5 / 1) (Ch 2, Ch 3)

**Enhancement** — Rewriting subtype that expands rough notes into full professional prose (Ch 5)

**Extracting (Task-Extracting)** — Pull specific fields, entities, or key points from text (Ch 5, Ch 9)

**Few-shot learning** — Multiple in-prompt examples teaching task and format (Ch 3)

**Foundation Model (FM)** — Broad pretrained model; text FMs include LLMs (Ch 3)

**Generating (Task-Generating)** — Create new text from a prompt/context (speech, marketing, quizzes) (Ch 7, Ch 9)

**Hallucination** — Fluent but false or fabricated content (facts, dates, URLs) (Ch 3, Ch 7)

**High (Creativity)** — Creativity preset = Temperature 1; more diverse outputs (Ch 3, Ch 9)

**Iterate Till Perfection** — Refine via follow-ups using chat memory instead of one giant prompt (Ch 4)

**Key Points (summarizing)** — Compress source into one or few essential statements (Ch 7)

**Large-Language Model (LLM)** — Text FM pretrained on large corpora; powers ChatGPT-like chat (Ch 3)

**LaunchPad / LaunchPad Playground** — GovTech WoG AI platform / demo UI used in screenshots (Ch 2)

**Low (Creativity)** — Creativity preset = Temperature 0; conservative/repeatable (Ch 3, Ch 9)

**Merging Summary** — Summarize and reconcile multiple notes of the same event (Ch 7)

**Objective (CO-STAR O)** — Explicit task the model must perform (Ch 4)

**One-shot learning** — Single in-prompt example (Ch 3)

**Prompt** — User input (question, statement, command) that initiates a model response (Ch 3)

**Prompt Engineering** — Crafting prompts for more accurate, relevant, efficient interactions (Ch 1, Ch 3)

**Response (CO-STAR R)** — Desired length and format (paragraph, list, table, report) (Ch 4)

**Rewriting (Task-Rewriting)** — New wording with similar meaning (simplify, correct, translate, enhance) (Ch 5, Ch 9)

**Roleplay Mode** — Multi-turn dialogue where the model asks questions before advising (Ch 8)

**Shortener** — Summarizing subtype: long text → shorter paragraph preserving main ideas (Ch 7)

**Simplification** — Rewriting for easier reading level/audience (Ch 5, Ch 9)

**Style (CO-STAR S)** — Persona or writing style to emulate (Ch 4)

**Summarizing (Task – Summarizing)** — Condense text; includes shortener, key points, merging (Ch 7, Ch 9)

**System Prompt** — Hidden product instructions that shape behaviour across apps (Ch 2)

**Temperature** — Randomness knob; 0 ≈ deterministic, 1 ≈ most creative (Ch 3)

**Token** — Smallest text unit the LLM processes; shared budget for prompt, history, reply (Ch 3)

**Tone (CO-STAR T)** — Affect of the reply (formal, casual, humorous, etc.) (Ch 4)

**Translation** — Rewriting across languages; verify with native speakers when stakes are high (Ch 5, Ch 9)

**Zero-shot learning** — Task posed with no examples (Ch 3)
