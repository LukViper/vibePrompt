# Glossary — Prompt Engineering Foundations (Richardson sample)

**Active learning (prompt refinement)** — Improving prompts using feedback from AI outputs and evaluation loops (Ch 7 preface/TOC).

**Artificial intelligence (AI)** — Field of making machines perform intelligent tasks; term coined at Dartmouth 1956 (Ch 1).

**Backpropagation** — Training method for neural networks highlighted from 1986 onward (Ch 2).

**Big data** — Large-scale datasets enabling richer model training and deep learning (Ch 2).

**Brute force attack** — Exhaustive search over candidates (e.g. Enigma settings) until success (Ch 1).

**Colossus / Bombe** — Early programmable / iterative machines used in WWII codebreaking lineage (Ch 1).

**Constraint (in prompts)** — Explicit limits on format, length, scope, or allowed behaviors (Ch 7).

**Contextualization** — Supplying background so responses fit the situation (Ch 7).

**Dartmouth conference (1956)** — Event marking AI’s formal birth as a discipline; McCarthy coined “AI” (Ch 1).

**Data-driven model** — Model whose behavior is shaped primarily by training data rather than hand rules (Ch 2).

**Deep learning** — Multi-layer neural learning enabled by data scale and specialized hardware (Ch 2).

**Directive prompt** — Prompt structure that instructs the model to perform a task or procedure (Ch 7).

**Edge case (prompts)** — Unusual input or failure path called out so the model handles it deliberately (Ch 7).

**Enigma machine** — WWII electromechanical cipher; shared rotor settings as secret key analogy (Ch 1).

**Generative model** — Model that synthesizes new samples (vs discriminative classification) — later chapters in TOC (preface).

**GPU / TPU** — Hardware accelerators that made large-scale neural training practical (Ch 2).

**Imitation game** — Turing’s conversational setup underlying the Turing test (Ch 1).

**Informative prompt** — Prompt structure that supplies facts, background, or given context (Ch 7).

**Interrogative prompt** — Prompt structure that asks for answers, analysis, or judgment (Ch 7).

**Machine learning (ML)** — Training models from data to perform tasks without exhaustively hand-coding rules (Ch 1–2).

**Natural language processing (NLP)** — Language-understanding/generation strand co-evolving with early AI (Ch 1).

**Neural network** — Layered computational model learning representations from data (Ch 2).

**Prompt** — Input that shapes an AI model’s behavior and output quality (Ch 1, 7).

**Prompt ecosystem** — Creation, structure, iteration, and evaluation of prompts around AI systems (Ch 7).

**Prompt engineering** — Craft of designing prompts to improve AI performance, reliability, and UX (Ch 1, 7).

**Prompt evaluation** — Measuring whether a prompt improves accuracy, relevance, or other outcomes (Ch 7).

**Rule-based system** — Hand-authored symbolic/if-then knowledge approach preceding data-driven ML (Ch 2).

**Statistical learning** — Estimating models from data distributions rather than pure symbolic rules (Ch 2).

**Support vector machine (SVM)** — Margin-based classifier family prominent in 1990s ML (Ch 2).

**Symbolic AI** — Intelligence via explicit symbols and rules (Ch 2).

**Transformer / GPT** — Later-architecture families central to modern prompting (preface + TOC Ch 4–6; not in sample body).

**Turing test** — Operational criterion: machine converses indistinguishably from a human (Ch 1).
