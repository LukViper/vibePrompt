# Glossary — The Prompt Canvas (Hewing & Leinhos)

**Analogical Prompting** — Instruct the model to invent useful examples for in-context learning before solving (Ch 2, Ch 7).

**Audience (Target Audience)** — Canvas cell describing typical users/customers and how to speak to them (Ch 3).

**Automatic Prompt Engineer (APE)** — Select/search prompts that yield higher output quality (Ch 2, Ch 7).

**Chain-of-Thought (CoT)** — Decompose reasoning into intermediate steps before the final answer (Ch 2, Ch 4, Ch 7).

**Context** — Canvas cell for situational background the model should treat as given (Ch 5).

**Custom GPT** — Specialized or company-primed LLM configuration with extra context/tools (Ch 8).

**Delimiters** — Markers that segment instructions vs data to reduce ambiguity (Ch 7).

**Emotion Prompting** — Append emotional stakes phrases to increase engagement/effort (Ch 2, Ch 7).

**Few-shot / One-shot / Zero-shot** — Learning regime by number of demonstrations in the prompt (Ch 2).

**Format / Output** — Canvas cell for length, structure, and medium of the response (Ch 6).

**Hyperparameters** — Generation controls such as temperature, top-p, frequency/presence penalty (Ch 7).

**In-context learning** — Task adaptation via prompt content without weight updates (Ch 1).

**Information space** — Whether context is undefined, explicit internal, or explicit external (Braun) (Ch 2, Ch 5).

**Iterative Optimization** — Feedback-loop refinement of prompts based on outputs (Ch 7).

**LLM Arena** — Side-by-side model comparison environment (Ch 8).

**Outcome goals (Braun)** — Learn, lookup, investigate, monitor/extract, decide, create (Ch 2).

**Persona/Role** — Canvas cell that casts the model’s expertise, viewpoint, and values (Ch 3).

**Placeholders** — Variable slots in reusable prompt templates (Ch 7).

**Plan-and-Solve** — CoT variant: understand → plan → execute step by step (Ch 2, Ch 4).

**Pre-train, Prompt, Predict** — NLP paradigm adapting tasks through prompts (Ch 1).

**Prompt Canvas** — Visual practitioner framework with four primary categories plus Techniques and Tooling (Ch 1).

**Prompt engineering** — Designing inputs that steer LLMs toward desired outputs (Ch 1).

**Prompt libraries** — Collections of reusable prompts/templates (Ch 8).

**Prompt patterns (White)** — Structural templates: Scope, Task/Goal, Context, Procedure, Role, Output, Termination (Ch 2).

**Prompting platforms** — Tools to design, test, and optimize prompts interactively (Ch 8).

**Rephrase and Respond (RaR)** — Restate the question in the model’s own words before answering (Ch 2, Ch 7).

**Re-reading (RE2)** — Instruct the model to read the question again (Ch 2, Ch 7).

**References** — Canvas cell for facts, files, policies, exemplars, and citations to use (Ch 5).

**Role prompting** — Assigning a defined role to guide tone and specificity (Ch 3).

**Self-Consistency** — Sample multiple CoT solutions; prefer the majority result (Ch 2, Ch 7).

**Self-Refine** — Iteratively improve an answer via model feedback until a stop condition (Ch 2, Ch 7).

**Step-by-Step** — Canvas cell that sequences the work the model should perform (Ch 4).

**Task and Intent** — Canvas cell stating the action-verb goal and objective (Ch 4).

**Thread-of-Thought (ThoT)** — Walk through context in manageable parts, summarizing/analyzing as you go (Ch 2).

**Tonality** — Canvas cell for tone attributes and optional brand/style inspiration (Ch 6).

**Tooling** — Canvas category for apps, libraries, extensions, arenas, custom GPTs, APIs (Ch 8).

**Tree-of-Thoughts (ToT)** — Explore multiple reasoning branches/perspectives (Ch 2, Ch 7).
